# Architectural Decision Records

Decisions that shape this project. Numbered, dated, append-only.

## Policy

1. **Append-only.** Never rewrite accepted ADRs. Supersede via new ADR.
2. **One decision per ADR.**
3. **Numbered sequentially** from 0001.
4. **Status lifecycle**: proposed → accepted | rejected | deprecated | superseded by ADR-NNNN.

## Format

[MADR](https://adr.github.io/madr/). See [TEMPLATE.md](./TEMPLATE.md).
