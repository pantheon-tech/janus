# Architectural Decision Records

ADRs document **decisions specific to this project** — beyond what janus provides as a baseline.

Don't write an ADR for inheriting janus defaults. Do write one when you deviate from a janus convention or make a non-obvious project-specific architectural choice.

## Format

[MADR](https://adr.github.io/madr/). See [TEMPLATE.md](./TEMPLATE.md).

## Policy

1. **Append-only.** Never rewrite an accepted ADR. Supersede via a new ADR that links back.
2. **One decision per ADR.**
3. **Numbered sequentially** from 0001.
