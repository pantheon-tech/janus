# Security Policy

## Supported Versions

Only the latest minor version of `janus` receives security fixes. Older versions may be patched at the maintainer's discretion.

## Reporting a Vulnerability

If you find a security issue in `janus` — including in a template that would propagate an insecure default to downstream projects — please:

1. **Do not open a public issue.**
2. Email: **daniel@skipper.kiwi**
3. Include a minimal reproduction and the affected file path / template.

You should receive an acknowledgement within 72 hours.

## Derived Projects

`janus` is a starter kit. Projects scaffolded from `janus` inherit its defaults but are independent repositories. Security issues in a derived project should be reported to that project's maintainer, not here.
